# 手動編集ガイド

## 手順

1. `ocr_raw_*.txt` ファイルを開き、取引明細部分を確認
2. `manual_edit_*.txt` ファイルに取引明細を手動で入力
3. 入力形式: `YYYY/MM/DD 金額 取引内容`
   - 例: `2025/03/15 50000 給与振込`
   - 例: `2025/03/20 -15000 ATM出金`
4. 手動編集完了後、`process_manual_files.py` を実行

## 注意事項

- 出金は負の金額（例: -1000）で入力
- 入金は正の金額（例: 1000）で入力
- 1行1取引で入力
- 日付は YYYY/MM/DD 形式で統一
