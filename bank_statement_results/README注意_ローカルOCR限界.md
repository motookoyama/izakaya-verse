# 【重要】銀行明細OCR・自動集計に関する注意（備忘録）

## 今回の案件まとめ
- 日本の銀行明細（PDF/画像）をローカルAI・OCR（Tesseract等）で自動集計しようとしたが、
  - 日本語表記・全角数字・表形式・罫線の影響で**正確な自動抽出は困難**だった
  - 取引日・金額・内容のペア抽出が安定しない
- Gemini（Google系）や外部高精度OCRサービスでは、PNG画像から数字や内容が比較的正確に認識できた
- しかし、**ローカル環境（Python/Tesseract）では銀行明細の完全自動化は現実的でない**

## ローカルでの自動集計の現状
- **CSVファイルのみが確実に自動集計可能**
  - 機械可読なテキストデータなので、PythonやExcelで安定して処理できる
  - 日本語列名や内容も問題なく扱える（エンコーディング注意）
- PDFや画像（PNG/JPG）は、OCR精度の限界により**人間の目視・手動補完が必須**
- 銀行サイトでCSVダウンロードが可能な場合は、**必ずCSVを利用すること**

## 今後の運用指針
- 過去分やPDF/画像しかない場合は、
  - OCRでできるだけテキスト化し、不足分は人間が目視で手動入力
  - もしくは外部高精度OCRサービスを活用
- **CSVが利用できる場合は、必ずCSVで集計・分析を行うこと**
- この現実・限界はユーザー全体に周知されるべき

---
